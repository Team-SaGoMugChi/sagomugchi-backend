# 위기 발화 판정 기준

`app/services/counsel_guardrail.py`의 `assess()`가 사용자 발화 한 문장을 3단계로 판정한다.
상담(`/counsel/turn`)과 일기 대화(`/diary/interview/turn`)가 같은 판정을 쓴다.

## 단계

| 단계 | 처리 | 사용자에게 보이는 것 |
|---|---|---|
| CRISIS | LLM을 부르지 않고 109 안내. 응답 `crisis: true` → 앱이 상담 중단 | 109 안내 배너 |
| CAUTION | 상담 계속. 시스템 프롬프트에 안전 확인 지침(`CAUTION_GUIDE`) 추가 | 평소 상담 (상담봇이 필요하면 부드럽게 확인) |
| NONE | 평소처럼 상담 | 평소 상담 |

## 판정 순서

1. **방법·계획 표현** (자살, 자해, 유서를 쓰, 약을 모아, 뛰어내리, 인생 끝내…) → CRISIS
   - 단, 정보·제3자 맥락(뉴스, 영화, 예방, 친구가…)이고 본인 의도(하고 싶, 할까…)가 없으면 → CAUTION
2. **죽음·소멸 바람** (죽고 싶, 사라지고 싶, 살기 싫, 그만 살고 싶…) → CRISIS
   - 바로 뒤가 부정("죽고 싶진 않아") → CAUTION
   - "죽고 싶" 바로 앞이 신체·사소한 이유(배고파, 졸려, 웃겨, 더워…) → CAUTION
   - 위 두 경우라도 진심 표시(진짜로, 진심, 농담 아니고, 오늘 밤)가 있으면 → CRISIS
3. **모호한 표현** (죽을래, 죽어야지) → CAUTION (진심 표시가 있으면 CRISIS)
4. 나머지 → NONE. "죽겠다 / 죽을 것 같다 / 죽는 줄"은 한국어 강조 표현이라 여기에 해당한다.

## 정한 이유

- **"죽겠다"는 안 잡고 "죽고 싶다"는 잡는다.** "~해 죽겠다"는 강조로 굳은 표현이고, "죽고 싶다"는 바람을 직접 말한다.
- **마음의 고통이 이유인 "죽고 싶다"는 낮추지 않는다.** 힘들어·우울해·외로워·지쳐는 실제 위기의 흔한 표현이다.
- **웃음(ㅋㅋ)은 근거로 쓰지 않는다.** 위기를 웃음으로 감추는 경우가 있다.
- **애매하면 CAUTION.** 사용자 화면에는 변화가 없어 오탐 비용이 낮고, 상담봇이 대화 맥락으로 한 번 더 거른다.
- **방법·도구는 상담봇이 어떤 경우에도 구체적으로 말하지 않는다.**
