# 표정·일기 감정 분석 직접 테스트

웹캠(과 마이크)으로 감정 분석이 실제로 어떻게 나오는지 확인하는 스크립트 두 개.
백엔드 루트에서 가상환경을 켠 뒤 실행한다. 영상 프레임과 녹음은 저장하지 않는다.

## 1. 표정 감정 — `python -m scripts.webcam_face_emotion`

필요한 것: `requirements.txt` 설치, 웹캠. 키는 필요 없다.
표정 모델(약 4MB)은 첫 실행 때 `.cache/mediapipe/`로 받는다.

1. 창이 뜨면 **5초 동안 무표정** — 이게 평소 얼굴(baseline)이다.
2. 표정을 지어 본다. 화면에 표정 감정 6종 막대, 표정 긍정도, 상담봇에 넘길 변화 문장이 나온다.
   - 미소 → 기쁨, 입꼬리 내리고 턱에 힘 → 슬픔·상처, 인상 → 분노, 눈썹 안쪽 올리기 → 불안, 눈 크게 → 당황
   - 슬픔과 상처는 얼굴로 구분하지 않아 같이 움직인다 (텍스트가 가른다).
3. 키: `b` 평소 얼굴 다시 측정, `a` AU별 z-score 보기, `q` 종료

## 2. 대화 일기 — `python -m scripts.diary_emotion_test`

필요한 것: 위 조건 + `.env`의 `CLOVA_SPEECH_INVOKE_URL`·`CLOVA_SPEECH_SECRET`,
`pip install -r requirements-kote.txt`(docs/KOTE.md), 마이크. 녹음 한 번마다 CLOVA를 한 번 호출한다(과금).

1. `b` → 20초 동안 화면 질문에 **평소처럼** 답한다 (무표정). 평소 얼굴·목소리 기준이 된다.
2. `r` → 앱 Step1처럼 **오늘 있었던 일 한 가지를 1~3분** 자유롭게 말한다. `r`로 끝낸다.
3. 30초 정도 뒤 결과가 나온다 — 전체 감정, 감정 흐름(arc), 불일치 여부.
4. 실제로 느낀 감정을 `1`~`7`로 골라 `s`로 저장한다 (AI 결과와 비교하는 정답지, 선택).

결과는 `.cache/diary_tests/`에 저장된다 (Git 제외 — 말한 내용이 들어 있다).

| 파일 | 내용 |
|---|---|
| `<시각>_analysis.json` | 분석 원본: 전체 감정(텍스트·표정·목소리 각각), 문장별 시간·감정·톤, 실제 느낀 감정(`self_report`) |
| `<시각>_video.json` | 숏폼 영상용(`oddo.diary_emotion.v0-sample`): 장면 후보, 감정 전환점, 문장별 감정. 맨 위 `설명`에 필드 뜻 |

## 알아둘 점

- 카메라에 **가까이** 앉을 것. 얼굴이 화면의 1/5 정도로 작으면 살짝 미소가 잡히지 않는다.
- 말하면서 짓는 표정은 약하게 잡힌다 (입 주변 AU가 발음 영향을 받음). 표정 긍정도는 말 사이사이 강한 순간(상위 25%)으로 요약한다.
- 가중치·문턱값은 이론 기반 잠정값이다 (`app/services/modality_emotion.py`, `multimodal_fusion.py`).
- 창이 안 뜨고 OpenCV 오류가 나면 headless OpenCV가 쓰이는 중이다 — 스크립트가 재설치 방법을 안내한다.
- macOS는 처음 실행 때 터미널의 카메라·마이크 권한을 허용해야 한다.
